Agent Skill / Coding Workflow

light-rip

Light RIP is a lightweight Review-Implement-Plan skill package for Claude Code and Codex coding workflows. It defines a compact tiered process for coding tasks: tiny tasks stay in the main session, medium tasks add reviewer subagent review, and large tasks split planning, implementation, and review across subagents while keeping final fixes and verification coordinated by the main session.

Autonomous Execution / Planning Workflow

claude-yolo-until-done

claude-yolo-until-done is a Claude Code workflow for turning an approved plan into durable autonomous execution. It combines a first-party grill-storm planning phase with worker and watcher execution, using explicit artifacts such as spec, plan, state, trace, and role-agent logs so long-running implementation can be resumed, audited, reviewed, and cleaned up deliberately.
