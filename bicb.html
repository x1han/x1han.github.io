Direct RNA-seq / Isoform Discovery

AIDRS

AI-Aided Isoform Discovery for direct RNA-Seq is a sequencing data-driven framework for full-length RNA isoform reconstruction and quantification from Oxford Nanopore direct RNA sequencing. It extends isoform discovery with coding potential prediction, translation start and stop codon identification, enhanced TSS/TES prediction, polyA-aware assessment, and annotation-guided filtering and rescue for low-abundance conserved isoforms.

Transcript Visualization / Publication Figures

drVizer

drVizer is a Python library for building transcript-structure figures from GTF models, BED annotations, and BAM coverage tracks. It is designed for direct RNA sequencing and transcriptomics workflows that need reusable, scriptable, publication-ready matplotlib figures with support for transcript-coordinate projection, annotation overlays, coverage aggregation, shared y-axis scaling, and repeated plotting through a builder-style API.
