Contributed Project / Claude Code Plugin

claude-hud

Claude HUD is a Claude Code plugin that makes session state visible below the input line, including context usage, rate-limit usage, active tools, running agents, todo progress, project path, and git branch. It uses Claude Code's native statusline API and transcript data, so it works inside the terminal without a separate window.

ZCode Extension / Community Plugin

ZCode-Timeline

ZCode-Timeline is a community-built ZCode extension that adds a vertical session timeline to the chat panel, with click-to-jump and hover previews for any user message. It installs as a one-shot patch of ZCode's app.asar (with a reversible original backup) rather than running a background daemon, and ships a standalone Windows installer and uninstaller.

Desktop Workspace / Tauri App

mXterm

mXterm is a local-first, cross-platform terminal and remote-operations workspace built on Tauri v2, React, and Rust. It unifies local shells, SSH, RDP, VNC, Telnet, and serial connections with SFTP file management, Docker, port tunneling, host monitoring, scheduled remote tasks, an AI terminal assistant, and MCP, all in a single lightweight desktop app with no Node/Express runtime dependency.
