Contributed Project / Claude Code Plugin

claude-hud

Claude HUD is a Claude Code plugin that makes session state visible below the input line, including context usage, rate-limit usage, active tools, running agents, todo progress, project path, and git branch. It uses Claude Code's native statusline API and transcript data, so it works inside the terminal without a separate window.
